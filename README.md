# GoSports

Static landing page for GoSports, served at [gosports.in](https://gosports.in).

## Structure

```
index.html          Homepage markup
assets/css/style.css Styles
assets/js/main.js    Nav toggle and contact form interaction
```

## Running locally

No build step required. Serve the directory with any static file server, for example:

```
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
